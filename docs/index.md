# Silicon Photonics — Plain-English Study Notes

Week-by-week, first-principles rewrites of the assigned sections of **Chrostowski & Hochberg, *Silicon Photonics Design: From Devices to Systems***, written for a reader from outside the field.

## How each day is laid out

1. **Big picture**: what problem the sections solve, with an everyday analogy.
2. **Background you need**: prerequisites built from scratch.
3. **The book's sections, in order**: one-sentence summary, plain-English explanation, every equation unpacked, key takeaways.
4. **Glossary** and **Check yourself** questions.

!!! tip "Study tip"
    Read the *Background* part first, then try the *Check yourself* questions before re-reading the sections you got wrong.
